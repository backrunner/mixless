# Repository instructions

Read [CONTRIBUTING.md](CONTRIBUTING.md) before making changes.

For user-facing work, follow [UI and product copy](CONTRIBUTING.md#ui-and-product-copy):
avoid AI slop, keep the interface and copy concise, and do not use dots or bullets
as inline text separators. These rules include settings, select options, buttons
and preset mapping controls, in every language.

Apply the [mixless brand guide](.agents/skills/mixless-brand/SKILL.md) to visual work.
