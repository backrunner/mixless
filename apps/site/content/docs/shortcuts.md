The highlighted deck receives selected-deck commands. Shortcuts do not run in import/help dialogs or file pickers; holding a key does not repeatedly trigger an action.

## Reference

| Keys | Action |
| --- | --- |
| Space | Play/pause selected deck |
| Z / X | Play/pause A / B |
| Tab | Select A / B |
| C / Shift+C | Set or return to temporary Cue / clear it |
| G | Fill the next empty hot cue |
| 1–8 | Selected deck hot cues 1–8 |
| Q W E R / U I O P | Deck A / B hot cues 1–4 |
| Shift + cue key | Assign AUTO / IN / OUT to a saved cue |
| S | Sync selected deck |
| L | Toggle selected deck loop |
| [ / ] | Halve / double loop length |
| Left / Right | Jump backward / forward one bar |
| Shift + Left / Right | Jump backward / forward four bars |
| F | Center the crossfader |
| Escape | Close a panel or cancel a row drag |
| Cmd+, | Open Preferences |
| ? / F1 | Show keyboard shortcuts |
