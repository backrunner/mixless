打开 **Preferences → MIDI Mapping**。列表包含所有支持的控制项，也包括尚未映射的控制项。唱盘/混音器线框图会高亮已有映射。

## 分配控制项

1. 启用 MIDI 输入设备。更换设备后，用 **Apply inputs** 重新连接。
2. 点击线框图上的控制项，上方提示会显示正在等待绑定的目标。
3. 转动硬件旋钮、移动推子或按下按钮。收到第一个匹配类型的信号后会自动保存，图中控件变绿，无需再按 **Assign**。

点击另一个控件即可继续绑定；**Cancel** 或 Escape 可取消等待，不改变映射。按钮松开信号不会触发绑定，学习 Jog 旋转时也会忽略触摸 note。如果收到的设备、通道和 CC / note 已绑定其他目标，该绑定会移到当前目标，提示中会注明原来的目标。

如需手动设置，在列表中选择控制项，指定设备、通道、CC 或 note，再按 **Assign**。编辑区的 **Learn** 会捕获信号供检查，再由 **Assign** 保存。学习期间会抑制演奏命令。

## 编码器与旋钮

Jog 和资料库浏览编码器支持相对 **1/127**、**65/63**、**1/65** 模式；其他旋钮还支持绝对 CC。**Auto** 保留旧版的绝对旋钮与二进制补码 Jog 行为。

请选择与控制器输出一致的模式。如果编码器突然跳变或方向不对，检查设备的 MIDI 说明和映射模式。

## 资料库控制

浏览编码器可选择曲目或歌单。可以为 A 唱盘、B 唱盘或当前唱盘分别分配载入按钮，方便不使用鼠标完成浏览与载入。

## 保存与复用

可以清除单个映射，或以 JSON 导入、导出。偏好设置与映射分别存入资料库数据库旁的 `preferences.json` 和 `midi.json`。

不含设备 ID 的旧映射匹配任意已启用输入。使用多个控制器时，建议明确指定设备，以区分各自的映射。
