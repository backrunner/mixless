按 **Cmd+,** 打开 **mixless → Preferences…**，选择 **Audio I/O**。

## 输出设备

选择主输出、采样率（设备支持时最高 192 kHz）、输出位深和缓冲区大小。**Apply audio** 会重新打开音频流，短暂打断播放。设备不可用或格式不受支持时，会报告错误并保留先前配置。

采样率与输出位深默认采用 **System / device current**，在打开输出或应用设置时读取设备当前的物理格式。macOS 下，每秒检查系统格式变化，变化后重新打开音频流以保持匹配；录音期间暂缓重开，直到录音结束。手动设置会修改 CoreAudio 硬件格式，并回读确认实际生效；位深菜单只列出所选采样率下设备支持的位深。设置失败会恢复原硬件格式。主输出的采样率与位深不会修改独立的耳机设备，预听会匹配耳机设备自己的物理格式。

音源在输出时转换到输出采样率，正常速度下保持播放时长与音调。混音和效果器内部采用 32 位浮点处理，最终由 CoreAudio 转换到设备的物理输出格式。**Current audio** 分别显示主输出、耳机的物理格式和处理流格式。提高采样率或位深无法恢复音源原本没有的细节，混音输出也不属于 bit-perfect 播放。

macOS 通过 CoreAudio 输出，默认使用 **Low latency (auto · 256 frames)**：为主输出和耳机预听分别请求 256 帧；若设备支持范围不包含 256 帧，则采用范围内最近的大小。无法查询缓冲区范围时保留设备默认值。已有的手动大小设置继续保留。

**Buffer size** 可选择 64、128、256、512、1024 或 2048 帧，作用于主输出和耳机预听；手动大小必须由两个已启用的设备支持。**Current audio** 显示主输出实际回调的帧数和 buffer 时长。256 帧在 48 kHz 下约为 5.33 ms，这是单个 buffer 的时长；设备、无线传输和音频处理还会增加实际输出延迟。

更小的缓冲区可降低延迟，但也减少音频处理的时间余量。如果播放出现断续，可以增大缓冲区，并检查设备支持的设置。

## 耳机预听

为 PFL 选择独立耳机输出。耳机总线位于推子之前，独立于通道推子和主音量；两个设备使用不同采样率时也能工作。耳机音量单独调整。

没有耳机输出时，只会禁用 PFL；Hot Cue 仍然可用。Hot Cue 用于跳转播放位置，PFL 用于监听通道。

## 增益与电平

| 控制项 | 作用 |
| --- | --- |
| 混音器 TRIM | 校准通道电平 |
| 唱盘 GAIN | 调整进入唱盘限制器的增益，范围 −12 至 +12 dB |
| 通道推子 | 设置唱盘限制器之后的音量 |
| Master GAIN | 调整进入主限制器的增益 |
| Master LEVEL | 设置主限制器之后的最终输出音量 |
| 耳机音量 | 独立设置耳机输出音量 |

PFL 监听经过唱盘限制器、但尚未经过通道推子的信号。Master GAIN 和 LEVEL 不改变耳机音量。

较长叠混出现能量损失时，AutoMix 可临时补偿最高 6 dB，**AUTO +…** 显示补偿量。手动调整增益会接管控制，临时补偿在混音结束后归零。

## 常规设置

General 保存波形布局、效果器显示、量化、Key Lock、vinyl/slip、交叉推子曲线与反向，以及滤波/EQ 共振。修改也会立即应用于当前会话。
