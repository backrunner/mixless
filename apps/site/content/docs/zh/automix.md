## 开始与播放顺序

选择歌单并开启 **AUTO**。空唱盘会先按列表顺序播放第一首可播放曲目，即使已打开随机播放也是如此。后续曲目按顺序或随机模式继续；每轮随机播放遍历所有条目后才重新洗牌，歌单持续循环。

选中歌单后，mixless 会在后台连续规划整个 set：每首的入点、上一段混音的结束位置以及承接的速度和调性，共同约束本首出点。列表和播放共用计划；下一轮循环单独规划，不把下一轮入点叠在本轮出点上。

## 如何选择过渡

mixless 结合局部曲速、乐句边界、调性兼容性、能量、节奏和人声信息，比较候选入口与出口。准备好的分轨和音符分析会进一步提供前景声部与和声变化的信息。

| 方式 | 音乐目的 |
| --- | --- |
| 乐句叠混 | 对齐乐句，让两首同时播放的曲目逐步交换空间 |
| 低频交换 | 重叠播放时，把低频从一首交给另一首 |
| Drop 切换 | 将识别出的 build-up 结尾接到下一首的 drop 或副歌 |
| 回声或滤波退出 | 在交接附近塑造退出曲目的声音 |
| 结构切换 | 不适合叠混时，在合适的音乐边界直接切换 |

过渡长度由音乐决定。合适的曲对可以进行较长的分层叠混，结构切换也可以是瞬间完成。Drop Cut 需要真实 build-up 结束和适合进入的段落证据。证据充分时，过渡也可以以 **Spinback**（出碟短促的加速回拉停碟）或 **Loop out**（出碟循环尾句，同时分轨或 EQ 在入碟之下将其抽离）收尾。不会让每组曲目都使用同一种技法。

自动退出必须落在已识别的段落边缘、有实际变化证据的乐句边界或音频末尾，仅按固定小节数计数不能决定切走。接入段也会与出碟段比较相对能量，避免强交接落在安静的淡入开头。手动 IN/OUT 仍优先。

分析结果是估计。节拍网格不确定、人声密集或结构不兼容时，可能选择保守的交接方式。正式使用陌生曲对前，先试听效果。

## 设定边界

按住 **Shift**，或点击唱盘的 **SHIFT**，再选择一个已保存的 Hot Cue，可以指定其角色：

- **AUTO**：普通 Cue，可作为参考锚点。
- **IN**：明确指定进入混音的位置。
- **OUT**：明确指定退出混音的位置。

更改角色不会改变 Cue 的保存位置。手动 IN/OUT 是硬约束；无法满足的窗口会显示错误，不会悄悄绕过。自动分析只填充空白 Cue，不覆盖你的手动修改。

## 观察交接

过渡条显示选中的窗口、倒计时或进度、技法和待进入唱盘的控制状态；对应区间也会在波形中高亮。

空闲唱盘会先准备 Cue、曲速、Key Lock、EQ 并关闭通道音量。交接时，AutoMix 可以控制播放、滤波、EQ、通道推子、交叉推子、选定的效果器和分轨音量。

## 随时接管

计划运行时可以使用 **PAUSE**、**RESUME**、**SKIP**。调整推子、EQ 或滤波只接管对应的控制项；手动载入曲目会接管 AutoMix。

较长叠混出现能量损失时，AutoMix 可以加入临时增益，唱盘上的 **AUTO +…** 显示补偿量。手动调整会接管控制，补偿在混音结束后归零。

测量出的频段比例还用于轻微、仅衰减的 EQ 校正：启用 Live moves 后，单曲分段校正最多 1.5 dB；叠混时的音色校正最多 2 dB。缺少频谱证据时保持中性，低频交换仍保留其必要的交接包络。

**Live moves**（Off / Subtle / Active）的 Subtle 档仅在有测量证据的蓄势与低人声乐句边界加入轻微滤波或最多约 −3 dB 的鼓声衰减；Active 允许更明显的动作及自动 Spinback。动作在交接前平滑恢复，手动操作对应控制后即在本曲内交还用户。

其他控制详见[唱盘与效果器](/docs/decks)和[音频电平](/docs/audio)。

切换歌单、调整顺序或完成下载、分析、分轨准备后，AutoMix 会重新规划后续队列。仍来得及准备安全交接时，空闲唱盘会更换为新候选，当前曲目继续播放；已经进入混音或来不及安全替换时，本次交接继续完成，新候选排到下一位。
