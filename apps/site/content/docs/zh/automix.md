## 开始与播放顺序

选择歌单并开启 **AUTO**。空唱盘会先按列表顺序播放第一首可播放曲目，即使已打开随机播放也是如此。后续曲目按顺序或随机模式继续；每轮随机播放遍历所有条目后才重新洗牌，歌单持续循环。

未手动选择排序模式时，AUTO 会优先使用有效的 **BEST** 缓存。没有缓存时，先按当前歌单顺序播放，同时在后台计算 Best。本次播放不会因计算完成而自动换序；结果供下次开启 AUTO 或手动选择 **BEST** 时使用。本次应用运行期间，每个来源列表分别记住手动选择的 **ORDER**、**SHUFFLE** 或 **BEST**，包括 **All Tracks**。切换来源时，恢复目标列表自己的选择；没有手动选择则检查它自己的 Best 缓存。恢复 **BEST** 也必须命中有效缓存；缓存缺失或失效时降级为 **ORDER** 并后台重算，计算完成后本次播放仍保持原顺序。使用 **Keep current** 浏览其他列表时，正在播放的来源模式保持不变。

**BEST** 计算期间仍可切换到 **ORDER** 或 **SHUFFLE**，无需等待。已有计算会在后台生成缓存，完成后不会改变当前选择。

mixless 会在后台连续规划 AutoMix 使用的歌单：每首的入点、上一段混音的结束位置以及承接的速度和调性，共同约束本首出点。列表和播放共用计划；下一轮循环单独规划，不把下一轮入点叠在本轮出点上。

在 **Preferences → General → AutoMix** 中，**On playlist change** 控制切换歌单后的行为：

- **Follow selected**（默认）：后续曲目跟随新选中的歌单。
- **Keep current**：继续使用原来的 AutoMix 歌单，可以自由浏览其他歌单。

选择会保存，并用于之后的歌单切换，包括 **All Tracks**。关闭再开启 AUTO，会从当前查看的歌单开始。修改正在播放的歌单仍会更新队列；删除该歌单会停止 AutoMix。

## 如何选择过渡

mixless 结合局部曲速、乐句边界、调性兼容性、能量、节奏和人声信息，比较候选入口与出口。准备好的分轨和音符分析会进一步提供前景声部与和声变化的信息。

过渡有重叠时，AutoMix 会检查该段实际播放的调性，包括上一段保留的变调和效果尾音。分析支持匹配时，会在进歌可听见之前，将其调整到最近的兼容调性，偏移限制在原曲上下两个半音内，并优先只移一个半音。音高在重叠期间保持不变。Vocal Ride 还会比较变调后的音符。调性相距更远时不移调；这种情况和调性不确定时，改用分离鼓组、滤波过渡或直接切换

关闭 **KEY LOCK** 时，曲速加快音高也随之升高，约 6% 相当于一个半音。重叠期间进歌保持的曲速若恰好等于调性所需的移调（误差 10 音分以内），AutoMix 会关闭该曲的 KEY LOCK 播放，不做变速拉伸和移调处理。唱盘的调性标记显示实际听到的调

独奏期间，AutoMix 可以在测量支持的较弱段落中逐步回原调。它会前瞻下一首的调性与出场窗口，选择完整或部分恢复，并配合平滑音高曲线、filter、EQ 和可用 stems。有明显人声、人声长音、高潮或时间不足时不回调；持续器乐声部只允许更小、更慢的调整。没有合适窗口就保留当前音高。手动调音仍有优先权；接管遮掩所用的控制或按 SKIP 会保留当时实际到达的音高，下一次过渡据此重新规划

对拍可能让进歌比原速更快或更慢。进歌独奏后，AutoMix 以过渡中使用的缓慢速率把它滑回原速；12% 的变化约需一分钟。只有下一首需要同方向调整时，才保留其中一部分，最多 6%。剩余时长不足时只恢复一部分。手动改变曲速即接管；按 SKIP 会直接到达滑动原定的目标曲速

以关闭 KEY LOCK 方式播放的曲目会完全滑回原速，音高随之回到原调，每秒变化不超过约 6 音分。回到原速后 KEY LOCK 重新开启。在这段滑动中按 SKIP 会保留当时的曲速和音高，KEY LOCK 保持关闭

| 方式 | 音乐目的 |
| --- | --- |
| 乐句叠混 | 对齐乐句，让两首同时播放的曲目逐步交换空间 |
| 低频交换 | 重叠播放时，把低频从一首交给另一首 |
| Drop 切换 | 将识别出的 build-up 结尾接到下一首的 drop 或副歌 |
| 回声或滤波退出 | 在交接附近塑造退出曲目的声音 |
| 结构切换 | 不适合叠混时，在合适的音乐边界直接切换 |

过渡长度由音乐决定。合适的曲对可以进行较长的分层叠混，结构切换也可以是瞬间完成。Drop Cut 需要真实 build-up 结束和适合进入的段落证据。证据充分时，过渡也可以以 **Spinback**（出碟短促的加速回拉停碟）或 **Loop out**（出碟循环尾句，同时分轨或 EQ 在入碟之下将其抽离）收尾。不会让每组曲目都使用同一种技法。

自动退出必须落在已识别的段落边缘、有实际变化证据的乐句边界或音频末尾，仅按固定小节数计数不能决定切走。接入段也会与出碟段比较相对能量，避免强交接落在安静的淡入开头。手动 IN/OUT 仍优先。

分析结果是估计。节拍网格不确定、人声密集或结构不兼容时，可能选择保守的交接方式。正式使用陌生曲对前，先试听效果。

## 设定边界

按住 **Shift**，或点击唱盘的 **SHIFT**，再选择一个已保存的 Hot Cue，可以指定其角色：

- **AUTO**：普通 Cue，可作为参考锚点。
- **IN**：明确指定进入混音的位置。
- **OUT**：明确指定退出混音的位置。

更改角色不会改变 Cue 的保存位置。手动 IN/OUT 是硬约束；无法满足的窗口会显示错误，不会悄悄绕过。自动分析只填充空白 Cue，不覆盖你的手动修改。

## 观察交接

过渡条显示选中的窗口、倒计时或进度、技法和待进入唱盘的控制状态；对应区间也会在波形中高亮。

空闲唱盘会先准备 Cue、曲速、Key Lock、EQ 并关闭通道音量。交接时，AutoMix 可以控制播放、滤波、EQ、通道推子、交叉推子、选定的效果器和分轨音量。

曲速差距过大、无法对拍时，准备好的分轨允许 AutoMix 为各声部分别计算进入和退出曲线。它搜索入碟自己的重拍，用实际可用的声部承接节奏变化，并分别调整两碟的音量和 EQ。无法确认兼容的旋律与失同步的鼓点会分开交接。技法名称不代表固定曲线；证据不足时仍保留保守交接

## 随时接管

计划运行时可以使用 **PAUSE**、**RESUME**、**SKIP**。调整推子、EQ 或滤波只接管对应的控制项；手动载入曲目会接管 AutoMix。

较长叠混出现能量损失时，AutoMix 可以加入临时增益，唱盘上的 **AUTO +…** 显示补偿量。手动调整会接管控制，补偿在混音结束后归零。

测量出的频段比例还用于轻微、仅衰减的 EQ 校正：启用 Live moves 后，单曲分段校正最多 1.5 dB；叠混时的音色校正最多 2 dB。缺少频谱证据时保持中性，低频交换仍保留其必要的交接包络。

**Live moves**（Off / Subtle / Active）的 Subtle 档仅在有测量证据的蓄势与低人声乐句边界加入轻微滤波或最多约 −3 dB 的鼓声衰减；Active 允许更明显的动作及自动 Spinback。动作在交接前平滑恢复，手动操作对应控制后即在本曲内交还用户。

其他控制详见[唱盘与效果器](/docs/decks)和[音频电平](/docs/audio)。

选择 **Follow selected** 后切换歌单、调整正在播放的歌单顺序，或完成其下载、分析、分轨准备后，AutoMix 会重新规划后续队列。仍来得及准备安全交接时，空闲唱盘会更换为新候选，当前曲目继续播放；已经进入混音或来不及安全替换时，本次交接继续完成，新候选排到下一位。
