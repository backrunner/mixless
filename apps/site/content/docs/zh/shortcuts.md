高亮唱盘接收当前唱盘快捷键。在导入/帮助对话框或文件选择器中不会触发这些快捷键，长按按键不会重复执行。

## 按键速查

| 按键 | 操作 |
| --- | --- |
| Space | 播放/暂停当前唱盘 |
| Z / X | 播放/暂停 A / B |
| Tab | 切换当前唱盘 A / B |
| C / Shift+C | 设置或返回临时 Cue / 清除 |
| G | 设置下一个空白 Hot Cue |
| 1–8 | 当前唱盘 Hot Cue 1–8 |
| Q W E R / U I O P | A / B 唱盘 Hot Cue 1–4 |
| Shift + cue key | 为已有 Cue 指定 AUTO / IN / OUT |
| S | 同步当前唱盘 |
| L | 开关当前唱盘循环 |
| [ / ] | 循环长度减半 / 加倍 |
| Left / Right | 后退 / 前进一小节 |
| Shift + Left / Right | 后退 / 前进四小节 |
| F | 交叉推子归中 |
| Escape | 关闭面板或取消曲目拖动 |
| Cmd+, | 打开设置 |
| ? / F1 | 显示快捷键 |
