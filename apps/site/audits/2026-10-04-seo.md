# mixless production SEO audit — 2026-10-04

Production: https://mixless.alkinum.com/

Status: deployed on 2026-10-04. Google Search Console was not accessed. See the deployment verification below.

## Confirmed live findings

- All 24 public pages returned HTTP 200 after following redirects. Each raw HTML response had one title in the head, a unique description and a visible H1. Titles matched Open Graph and Twitter metadata.
- All 23 non-root sitemap/canonical URLs ended in `/`, but Cloudflare redirected them to URLs without `/` (HTTP 307). Thus the preferred URL redirected away from itself.
- All 12 Chinese pages returned `<html lang="en">` before JavaScript. Hydration changed this to `zh-CN`. This is an HTML correctness problem; it is not proof that it caused Google to rewrite a title.
- Homepage structured data already included a valid WebSite nested under WebPage.isPartOf. The absence of a separate top-level WebSite is not itself a defect. Alkinum was incorrectly represented as a Person.
- robots.txt allowed crawling and referenced the production sitemap. Public responses did not contain noindex; hreflang URLs matched sitemap language alternates. Social images and both favicons were accessible. Unknown routes returned real HTTP 404.
- Googlebot-UA requests and an ordinary browser received the same homepage title. A user-agent override does not verify genuine Googlebot access or its index.
- The external search provider returned no results for `site:mixless.alkinum.com`; this does not establish Google index status.

## Deployed corrections

- Use Cloudflare force-trailing-slash handling so prerendered canonicals, hreflang, sitemap and final served URLs agree. Existing extensionless URLs continue to redirect to the preferred URL.
- Use the framework page/locale resolver in a SvelteKit server hook to emit correct lang and dir in prerendered HTML.
- Reuse the framework's existing nested WebSite, avoid adding a duplicate entity, and classify Alkinum as an Organization. The regression check recursively counts WebSite entities.
- Set homepage titles to `mixless — Free DJ Software for macOS` and `mixless — 免费 macOS DJ 混音软件`, with localized descriptions. Existing article titles remain page-specific and branded.

## Indexing follow-up

For subsequent deployments, rerun:

```sh
SITE_TEST_URL=https://mixless.alkinum.com pnpm test:seo
```

The test writes `seo-audit.json` into its Playwright output directory and attaches it to the results. Inspect the root and Chinese homepages in Google Search Console, compare the live test HTML with the indexed HTML and Google-selected canonical, request indexing for the homepages, and resubmit the existing sitemap. These require account access and were not performed.

Google may choose its own title link. Updates require recrawling and processing and may take days to weeks; local or user-agent tests cannot guarantee the search result presentation.

References: [Google title links](https://developers.google.com/search/docs/appearance/title-link), [Google site names](https://developers.google.com/search/docs/appearance/site-names), [Cloudflare HTML routing](https://developers.cloudflare.com/workers/static-assets/routing/advanced/html-handling/), [SvelteKit hooks](https://svelte.dev/docs/kit/hooks).
