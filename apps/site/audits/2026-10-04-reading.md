# Reading surfaces and svedocs upgrade — 2026-10-04

Status: deployed on 2026-10-04. See the deployment verification below.

The production `/support` page had two consecutive separators: the hero's bottom border and the first prose H2's top border. The framework also added 32 px of prose padding and 19.2 px above H2s. This came from shared theme CSS, not support content.

All 22 English/Chinese reading routes were visited on production at desktop and mobile widths, with screenshots and computed styles captured for 44 views. They contained 94 H2s per viewport, all with a 1 px top border. Article/page outer frames were already absent; there was no horizontal overflow in these live views.

The fix applies to every reading page: use `theme.readingStyle: 'plain'`, keep open article/page surfaces, remove decorative prose H2 borders and top padding, and remove the inherited prose top padding. The hero retains one bottom divider. Table cells, code blocks, navigation controls and keyboard focus retain their useful boundaries. Standalone-page brand kickers now render lowercase `mixless`.

The framework and CLI were upgraded together from 0.2.1 to 0.2.2 using `pnpm exec svedocs upgrade 0.2.2 --package-manager pnpm`. The npm registry's `latest` tags for both packages and the [official release](https://github.com/backrunner/svedocs/releases/tag/v0.2.2) were checked. The lockfile was updated without changing direct dependencies other than the two svedocs packages; pnpm also reconciled the `@types/mdast` to `@types/unist` snapshot.

Validation against the actual local Cloudflare asset router:

- Type check: 0 errors, 0 warnings.
- Content check: 24 pages, 122 search records, 0 errors, 0 warnings.
- Static build and Cloudflare deployment dry-run: passed.
- Browser suite: 24/24 passed across desktop and mobile.
- Reading audit: all 22 reading routes under both OS color preferences at both viewport sizes, totaling 88 views; no decorative H2 borders, article frames, pixel corners/grid, excessive first-heading gaps or horizontal overflow.
- SEO checks: all 24 pages with JavaScript disabled, plus hydrated titles and language navigation, passed after the upgrade.
- Keyboard focus, code-block borders, table-cell borders and code-copy control visibility passed.

`tests/reading.spec.ts` saves a full-page screenshot for each route and a `reading-audit.json` with the computed style evidence. Results are under `test-results/svedocs-0.2.2/`. Desktop/mobile contact sheets of all reading pages were also visually inspected. Production baseline screenshots and measurements are in `/tmp/mixless-border-before/`; the contact sheets are in `/tmp/mixless-reading-gallery/`.

The release includes the SEO repairs described in [the SEO audit](./2026-10-04-seo.md). No Git commit was performed.
