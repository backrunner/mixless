# 07 — UI

参考 djay Pro 2-deck Pro mode + rekordbox tempo 区 + Traktor 顶栏分组。**GPUI 0.2（纯 Rust，GPU 渲染）**，无 web 栈。播放真相在 Rust；`UiState` 只镜像 `EngineSnapshot`（活动时 VSync 更新；后台 16 ms 轮询 + MIDI drain）。

## 布局

```
TopBar: Logo | 设备/采样率 | Q · AUTO · 波形布局 · FX · xrun · MASTER 旋钮
WaveStrip A/B（或 CENTER 模式：竖波形夹住 mixer）
Deck A | [vwave A] Mixer [vwave B] | Deck B
  Deck: 表头(标题/BPM/Camelot/剩余) | tempo 栈(SYNC/KEY/全高 pitch 推杆) | jog+进度条 | PLAY/CUE | 8 Hot Cue 垫 | LOOP 列
  Mixer: 双通道固定宽度 — TRIM/FILTER/RES 顶排；EQ 与推子并排，PFL 在推子底部；crossfader 独立底栏
FxBar: 左右每碟各并排 4 个紧凑 insert（◀ 效果名/锁定开关 ▶ / MIX 旋钮 / HOLD 瞬时应用），两侧镜像排列、中央 FX 标签
Library: 左侧 LIBRARY 标题栏 + 播放列表树；右侧当前来源/计数/导入工具栏 + 虚拟化曲目表；占用剩余高度
```

## 视觉

哑黑 `#0A0A0B` / 面板 `#141416` / 圆角 8px 卡片。Deck A 琥珀 `#FFB224`、Deck B 橙红 `#FF5238`；频谱波形独立使用低频红橙、中频绿色、高频青蓝的混色；对称峰值包络 + 较暗 RMS 主体，固定播放线，分析节拍线按源时间定位。推子/旋钮/碟盘为 canvas 自绘拟物件：金属斜面、拉丝滚花、镜面高光、双层投影、凹陷轴心/凹槽。

## 组件

`src/controls.rs`（旋钮/推子/表/碟盘/按钮）、`src/wave.rs`（滚动波形）、
`src/views/{topbar,deck,mixer,library}.rs`、`src/state.rs`（镜像 snapshot + 拖拽调度）。

拖拽模型：控件 mouse-down 记录 `DragCtl`，root 统一 mouse-move 分发，拖出控件不丢。搓碟 delta 5ms 合并且**累积不丢弃**。

Deck：封面字母、曲名、BPM、Camelot、pitch、jog、8 Hot Cue、loop、SYNC。
Mixer：TRIM、3-band + kill、filter、fader、PFL、xf。无耳机设备时仅 PFL disabled。

## 交互

| 动作 | 行为 |
|------|------|
| 拖 jog | 竖直位移 → 累积合并 5ms `Jog { delta_frames }` |
| 双击 jog | play/pause |
| 单击 Hot Cue | 已设置则跳转，空垫则在当前播放头设点 |
| Shift+单击 | 设 hot |
| 点 loop / ▲▼ | `SetLoop` / 倍增倍减 |
| 拖波形 | 横向／纵向抓取移动，源时间与指针方向相反；松手提交最终位置，保留播放／暂停状态 |
| SYNC / S | 启用／关闭 Beat Sync；该碟跟随另一碟，BPM＋拍相位持续锁定；MASTER / SYNC … / SYNC 区分主碟／等待／锁定 |
| 双击曲目 | load 到焦点碟 |
| 拖曲目到 A/B | 目标碟高亮，松手后后台加载到目标碟 |
| + Files / + Folder | 异步选择文件或多个文件夹，后台递归扫描、过滤格式并去重；按音频直属文件夹建立独立 playlist，以完整路径区分同名文件夹，重复导入增量添加 |
| macOS 菜单 Mixless → About Mixless | 独立关于窗口显示版本及构建信息 |
| Tab / Shift+Tab | 切换选中碟 A/B |
| 空格 / Z / X | 选中碟 / A / B play/pause |
| C / G | cue 1（空则设点）/ 下一个空垫快速设点 |
| 1–8 | 选中碟 Hot Cue 1–8（空则设点） |
| Shift + cue 键 | 在当前播放头设置/覆盖对应点 |
| QWER / UIOP | A/B Hot Cue 1–4 |
| L / [ / ] | 循环开关 / 减半 / 加倍（1–16 小节） |
| ← / →（加 Shift）| 后退/前进 1 小节（4 小节） |
| ? / F1 / macOS 菜单 Help → Keyboard Shortcuts | 快捷键帮助 |
| F | xf 回中 |
| S | 选中碟 SYNC |
| 点击 FX 名称 | 锁定 / 解除该效果（无需独立 ON/OFF） |
| 按住 FX HOLD | 按下启用，抬起时恢复按下前的锁定状态 |

## 禁止

- 任何 web/webview 技术栈。
- UI 侧积分 playhead。
- 无第二设备时把 PFL 接到 Master。
- 无第二设备时禁用 Hot Cue 垫。

键盘控制位于 `src/shortcuts.rs`；帮助位于 `src/views/shortcuts.rs`。弹窗/输入/文件选择时屏蔽演奏键，长按不重复触发。自定义 keymap、完整 MIDI = P1。

Library 左栏分别显示 LOCAL FOLDERS 和远端／手动 PLAYLISTS；本地子文件夹单独成表，不汇入父文件夹。启动补齐已有本地曲目的文件夹分组，并默认选中一个 playlist；导入后选中首个成功导入的 playlist。All Tracks 仅手动选择时展示总库，Automix 使用选中 playlist 的曲目。

纵向推子的绘制、刻度和鼠标映射共用推子帽中心的有效行程；抓住推子帽不跳值，点击槽道跳至对应位置。通道 level 为底部 0、顶部 100 的单向推子，启动与双击均回到底部 0；tempo 默认与双击均在中央 1.0（0%）。tempo 顶部的 SYNC/Key Lock 与 Key 旋钮并排，让推子在现有面板中获得至少 112px（紧凑）/136px（常规）的高度。主界面不设 Help / About 按钮，启动不弹关于窗口。
