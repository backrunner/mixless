# 07 — UI

参考 djay Pro 2-deck Pro mode + rekordbox tempo 区 + Traktor 顶栏分组。**GPUI 0.2（纯 Rust，GPU 渲染）**，无 web 栈。播放真相在 Rust；`UiState` 只镜像 `EngineSnapshot`（活动时 VSync 更新；后台 16 ms 轮询 + MIDI drain）。

## 布局

```
TopBar: Logo | 设备/采样率 | Q · AUTO · 波形布局 · FX · xrun · MASTER 旋钮
WaveStrip A/B（或 CENTER 模式：竖波形夹住 mixer）
Deck A | [vwave A] Mixer [vwave B] | Deck B
  Deck: 表头(标题/BPM/Camelot/剩余) | tempo 栈(SYNC/KEY/全高 pitch 推杆) | jog+进度条 | PLAY/CUE | 8 Hot Cue 垫 | LOOP 列
  Mixer: DJM 式双通道列 — TRIM+FILTER 顶排、HI/MID/LOW+kill、PFL、通道推子+双 LED 表、crossfader
FxBar: 每碟 3 insert（◀ 效果名/锁定开关 ▶ / MIX 旋钮 / HOLD 瞬时应用），对齐三栏网格
Library: FILES|SPOTIFY 标签 + 播放列表 | 搜索/导入/URL | 虚拟化曲目表
```

## 视觉

哑黑 `#0A0A0B` / 面板 `#141416` / 圆角 8px 卡片。Deck A 琥珀 `#FFB224`、Deck B 橙红 `#FF5238`；频谱波形独立使用低频红橙、中频琥珀、高频青蓝。推子/旋钮/碟盘为 canvas 自绘拟物件：金属斜面、拉丝滚花、镜面高光、双层投影、凹陷轴心/凹槽。

## 组件

`src/controls.rs`（旋钮/推子/表/碟盘/按钮）、`src/wave.rs`（滚动波形）、
`src/views/{topbar,deck,mixer,library}.rs`、`src/state.rs`（镜像 snapshot + 拖拽调度）。

拖拽模型：控件 mouse-down 记录 `DragCtl`，root 统一 mouse-move 分发，拖出控件不丢。搓碟 delta 5ms 合并且**累积不丢弃**。

Deck：封面字母、曲名、BPM、Camelot、pitch、jog、8 Hot Cue、loop、SYNC。
Mixer：TRIM、3-band + kill、filter、fader、PFL、xf。无耳机设备时仅 PFL disabled。

## 交互

| 动作 | 行为 |
|------|------|
| 拖 jog | 竖直位移 → 累积合并 5ms `Jog { delta_frames }` |
| 双击 jog | play/pause |
| 单击 Hot Cue | 跳转（永远可点） |
| Shift+单击 | 设 hot |
| 点 loop / ▲▼ | `SetLoop` / 倍增倍减 |
| SYNC | `Sync { deck, keylock }` |
| 双击曲目 | load 到焦点碟 |
| 空格 | 选中碟 play/pause |
| QWER / UIOP | A/B Hot Cue 1–4 |
| F | xf 回中 |
| S | 选中碟 SYNC |
| 点击 FX 名称 | 锁定 / 解除该效果（无需独立 ON/OFF） |
| 按住 FX HOLD | 按下启用，抬起时恢复按下前的锁定状态 |

## 禁止

- 任何 web/webview 技术栈。
- UI 侧积分 playhead。
- 无第二设备时把 PFL 接到 Master。
- 无第二设备时禁用 Hot Cue 垫。

完整 keymap、MIDI = P1。
