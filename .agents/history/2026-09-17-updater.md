# Updater audit — 2026-09-17

## Corrected behavior

- Joining a launch check from the menu now keeps the manual flag through every worker status, so terminal results are visible. Consecutive fast checks have distinct request identities so a repeated result refreshes its notice.
- A ready update remains ready until restart; another check cannot download it again.
- Beta discovery reads all release pages and selects the highest semantic beta version, ignoring drafts and releases without a manifest. Feed channel/version and bundle channel/version must agree; build metadata does not imply a newer release.
- Unknown-length downloads still enter Downloading immediately and finish at 100%; short responses, HTTP failures, invalid JSON and digest mismatches fail without activation. Client setup failure no longer silently loses configured timeouts.
- Installation stages a complete bundle on the destination volume, verifies that copy, and uses macOS `renamex_np` to atomically exchange app directories. Copy, validation or activation failure leaves the old app intact. Directory modes, symlinks and executable permissions survive copying.
- A persistent per-app lock serializes installers. The installed version is checked again under the lock after downloading, so a different updater's completed newer version is retained. An empty hidden `.Mixless.app.install.lock` file remains beside the app; the OS releases its lock on exit/crash.
- Release credential selection now uses an API key only when all three API fields exist, matching the preflight fallback to complete Apple ID credentials. Manifest hashing uses the expected DMG filename directly.
- Desktop CI now runs tests, including updater/local HTTP and installer regressions.

The native integration resolves the live beta feed, downloads the published DMG, checks SHA-256, mounts it, verifies strict code signing, Gatekeeper, identifier/team, version and channel, then checks a staged copy and atomically replaces a temporary app bundle. A second same-version install preserves the bundle inode. The copied app passes stapler validation and its shipped executable starts successfully with `MIXLESS_INSTALL_ONLY=1`. Rejections for wrong version/channel and malformed DMG app layout are also covered.

Published artifact: `Mixless-macOS-0.1.0-beta.2.dmg`, 33,843,871 bytes. SHA-256: `0c1ec95d6f2b10eb85d3e1e753176a52ba94dd02b4f393a37045be4341a2f006`. Release workflow run 35078297783 completed successfully. The release is immutable and was not replaced by this audit.

A local HTTP test initially exposed a test-fixture race: reading only one TCP packet could leave request headers unread and reset the response connection. The fixture now consumes the complete headers before responding; the complete desktop suite subsequently passed.

## Limits

- Only beta.2 is currently publicly released; GitHub's stable latest endpoint returns 404. Stable channel/version policy is covered by local tests, but a published stable-to-stable update could not be exercised.
- The native test reinstalls the same signed package through the atomic installation primitive, then tests the production equal-version no-op. Newer/older version decisions are tested separately; it is not a two-version signed upgrade rehearsal.
- The executable smoke exits before UI/audio startup. Menu gestures, update banner painting, a complete GUI relaunch, and installation on a protected or non-APFS volume were not exercised.
- No user app in /Applications, library, secrets or release tags were changed. These updater fixes reach installed clients only after a subsequent signed release.
