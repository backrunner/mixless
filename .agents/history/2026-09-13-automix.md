# AutoMix、列表显示与模型评估：2026-09-13

本记录合并被后续实现替代的根目录逐轮报告。当前规则见 [AutoMix 参考](../reference/AUTOMIX.md)，15 个教学来源及模型原始文档见 [研究依据](../reference/automix-research.md)。以下结果对应本轮工作区，不代表之后的代码或所有设备。

## 本轮修改

- 开启 AUTO 后，列表波形显示 IN/OUT 与入/出混音区间；瞬切显示实际切点，不把调度准备期当作叠混。当前计划优先于相邻曲对预估；乱序只显示已确定曲对。重排、修改 Cue 和重新分析使后台预览失效并刷新。
- SQLite 刷新/重新导入保留手动顺序与重复次数，新条目追加。记忆所选列表。正常退出等待正在写入和待写入的排序操作，修复“拖完马上退出”丢失后续操作的路径。
- 去掉 drop 后固定一小节延迟和相关 recovery 偏移，不强制在高潮后才开始铺入下一首。保留最终退出不能截断已识别高潮的检查，允许适当的低能量层在其下方同步播放。
- 混音长度使用实际结构跨度及 24/32/48/64 小节等候选；相容长窗口获得持续性评分。稀疏无鼓区间只在两侧节拍锚点可靠、预测漂移小的情况下桥接，不以固定 16 小节数直接拒绝。
- 音量/中频退出可以利用完整重叠区间与测得的人声空隙；额外比较整段移调后的 Chroma 进行，持续不相容会降低普通叠混评分。它仍是频谱启发式，不是 Melodyne 音符识别。
- DropCut/DryCut 支持零小节计划，移除内部准备小节。临近真实结构边界才开启 AUTO 也可完成合法瞬切。修复自然 EOF 最后一帧造成切歌等待的问题。
- 整理根目录 Markdown：用户入口、贡献规范和第三方声明保留；工程参考与历史记录移入 `.agents`，删除四份过时/重复的 AutoMix 逐轮报告并合并有效内容。

这些变化没有按曲名或指定曲对编写规则，分析缓存仍为版本 13。

## 分轨与音符：本地原型实测

用 Lost & Found 145–170 秒的 25 秒片段验证 MLX HTDemucs、HTDemucs FT，并在分离的人声和 instruments 上运行 Basic Pitch ONNX。输出为对齐的 vocals / drums / instruments 三轨浮点 WAV、MIDI 和带原曲时间的音符 JSON。instruments = bass + other，不独立标准化各 stem。

| 项目 | HTDemucs | HTDemucs FT |
| --- | ---: | ---: |
| 分轨时间 | 4.28 秒 | 16.04 秒 |
| 音符推理时间 | 5.81 秒（含首次 JIT） | 1.69 秒（缓存已热） |
| 音符事件 | 261 | 268 |
| 原始重构残差 RMS | 0.01683 | 0.04944 |
| 原片段 RMS | 0.35807 | 0.35807 |

每轨均为 44.1 kHz、双声道、1,102,500 帧且全为有限值。残差不是分轨准确率，FT 残差更高也不能推导其听感更差。stem 峰值可能超过 1，保存浮点值没有剪裁；接入正式播放前需要统一 headroom 和混合一致性处理。模型加载/下载不计入上述分轨时间，冷下载的 FT 加载耗时约 55.4 秒。

结果在 `target/stem-review/lost-found-v2/` 与 `target/stem-review/lost-found-ft/`；依赖版本及 ONNX 模型摘要写入各自 `analysis.json`。Basic Pitch ONNX SHA-256：`2c3c1d144bfa61ad236e92e169c13535c880469a12a047d4e73451f2c059a0ec`。可重跑入口与依赖见 [研究依据](../reference/automix-research.md)。

SoundAnalysis 只提供分类补充，不能独立满足分轨/乐谱需求。MLX 分轨和 ONNX 音符原型尚未接入默认分析或实时播放；也未验证 ONNX 版本 Demucs、分轨听感、标注音符准确率和整轨并发导入负载。
