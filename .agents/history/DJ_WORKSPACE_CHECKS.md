## 后续修订：波形与自动接歌

- 走带使用 CoreAudio playback 时间戳插值，避免 512-frame 回报与 120 Hz 刷新不整除产生的重复位置和跳步；拖动、暂停、换歌与设备停滞时使用真实引擎位置。局部 BPM 的细微估计变化不再伸缩波形视野。
- 波形缓存版本 **2**：32 source frames/bin，最多 1,048,576 列，正／负峰与 RMS 升至 16 位；四个独立频段，16 ms 颜色能量平滑，不平滑瞬态位置。红低频、黄低中频、绿高中频、蓝高频依据 [djay 波形说明](https://help.algoriddim.com/user-manual/djay-pro-mac/mixing-basics/waveforms)。绘制对相邻列和多分辨率层连续插值，并对像素边缘做覆盖抗锯齿。旧版波形首次后台重建，之后复用新缓存。
- 分析版本 **8** 保存多组 In／Out 区域及接点局部 key、RMS、人声／kick 证据。曲对比较区域与不同重叠长度，约束落点、双前景、低频交换和速度变化。桌面允许暂停入碟提前做最多 ±2 半音的和声修正；区间、调性和移调保持有回归覆盖。
- 入碟提前设置 Cue、rate、pitch、key lock、EQ／filter 和关闭的 Level。音量衰减通过真实通道 fader 执行，trim 保存静态补偿。过渡条显示技法、倒计时／进度、两侧窗口和实际入碟 BPM／key／Level／Echo send，波形高亮所选窗口。
- 自然 EOF 早于下一个 32-frame 自动化控制点时会接续入碟，修复最后不足一个控制块导致的等待死锁。回归完成五次曲对调度、覆盖列表回绕，且验证重叠中关闭 AUTO 与手动双碟中重新开启。
- 原生 UI 验证使用相同隔离合成资料库，1542×768 窗口，Master 为 0%。已核对双碟彩色滚动、播放中抓动、待命 Cue／Level、A→B／B→A 交接后自动准备下一组、暂停及关闭后继续播放。稳定双碟段 CPU p50 **4.62–4.85 ms**、p99 **5.12–6.29 ms**；帧间隔 p99 **9.41–10.35 ms**。这属于 CPU 与提交间隔测量，不是 GPU 扫描输出或真实音乐试听结论。

- 本轮独占 Release 回调测试：256-frame 双碟 p50 **0.195 ms**、p99 **0.214 ms**（预算 5.333 ms）；128-frame 抓碟 p50 **0.086 ms**、p99 **0.108 ms**（预算 2.667 ms）。70 个效果器最慢项 Echo p99 **0.0654 ms／256 frames**，两项预算测试均通过。

更完整的规划规则和 DJ 教程来源见 [AUTOMIX.md](../reference/AUTOMIX.md)。

## 本轮：多阶段技法、列表波形和固定指针

- 规划按实际乐句／区域长度选择跨度，支持 24、48、64 小节等长混，及约 40 ms 的干声短切。长混有独立高频、低频、中频交接和保持段，结合非线性 crossfader／Level／filter；有证据时选择短 Echo 尾部。全套 46 项规划回归通过，包括频段功率连续性、前景保护和可选 FX。
- 曲对评分保留候选之间的差异，完整控制包络只为当前最佳候选生成。44.1／48 kHz 双向实际渲染的最大播放头相位差 **0.000236 拍**，不代表所有音乐的声学对拍误差。
- 列表加入定宽、完整首尾波形；和走带共享频谱颜色／峰值／RMS 绘制。编号彩色底部旗标与 Cue pad 一致，缩略图由后台工作线程生成，最多缓存 256 行。
- 原生界面核对：开头指针固定、暂停跳 Cue 3 对齐指针、SET IN 1／SET OUT 8、出点旗标同步到列表、右键清除、双碟播放中拖动、A／B 行标。默认窗口与放大窗口均检查。使用隔离合成资料库，Master 为 0%。
- 第一测量段（240 帧／组）双碟 CPU p50 **4.47–4.61 ms**、p99 **5.05–8.66 ms**；帧间隔 p99 **9.44–10.04 ms**。后续段出现 p99 **10.90 ms** 的帧间隔波动。列表加入完整波形后没有观察到明显的持续 CPU 增长；这不是 GPU 呈现或所有机器帧率的保证。
- 界面测试发现首拍之前的手动 IN 会让该曲被跳过，已修复为从原始 Cue 进行保守短桥接，并以回归验证原速／原调保持。另增加缓存读取不恢复已删除 Cue 的回归。手动 Cue 在重新分析时仍优先于自动槽位。
- 关闭测试实例后串行 Release 测量：256-frame 双碟 p50 **0.199 ms**、p99 **0.236 ms**，预算 5.333 ms；128-frame 抓碟 p50 **0.090 ms**、p99 **0.114 ms**，预算 2.667 ms。70 项效果最慢 PitchDelay p99 **0.0424 ms／256 frames**。两个性能测试通过。

## 本轮：Cue 操作、停盘与空碟入口

- 移除 SET IN／OUT；独立 SHIFT 放在 SYNC 左侧，Tempo 恢复 112 px／136 px 最小推子高度，SYNC／KEY LOCK 保持原先的两行。
- 数字 Cue 空白时创建，有值时直接跳转；Shift＋数字选择 AUTO／IN／OUT，位置不变。临时 CUE 独立，首次创建、再次返回，400 ms 长按删除，走带用 T 旗标；加载另一曲清空。暂停跳 Cue 后播放头精确停留在目标帧。
- 短按 Play 松开立即停，长按 400 ms 触发 1.2 秒音频时钟降速、降调和尾部衰减；Key Lock 不抵消 Brake，结束后保留 tempo／key 参数。按住期间换曲或窗口失去焦点会取消待处理手势。
- 连续 Cue 保留尚未结束的 6 ms 声音衔接，预分配尾音缓冲复用，无数据库读写。44.1／48 kHz、每 64 frames 连续触发、time-stretch／key shift、下一回调落点、非静音与采样连续性回归通过。
- 用户 AUTO Cue 加入候选锚点；多个 IN／OUT 是可选窗口。可靠网格使用相邻小节，无可靠网格时保留实际标记。已过去的 OUT 不阻止后续播放，原速短桥接仍检查用户 IN 和曲内范围。
- 空碟误按播放保持停止；空碟 AUTO 实际从首曲推起 Level，按开头人声／鼓点选择是否配合 Filter。乱序模式首曲顺序、音频进度驱动的非线性淡入、中途关闭和连续列表循环有回归覆盖。
- 隔离原生 UI 已核对：空碟状态、首曲启动和可见 Level 淡入、数字 Cue 创建、走带／列表旗标同步、Shift 用途选择不挪位置、临时点创建／返回／快捷键清除、短按停止、双碟播放中连续 Cue。长按阈值由手势状态测试验证，完整降速与停止由实际离线音频验证；原生自动化没有可指定时长的按住 API。
- 双碟播放、默认 1229×768 窗口的 CPU p50 **4.12–4.29 ms**，p99 **4.51–5.42 ms**；帧间隔 p99 **9.13–9.62 ms**。Master 为 0%，此检查不代表真实音乐试听。
- 按最新反馈，将 SHIFT 移至 SYNC 左侧的独立横向位置；默认窗口再次确认 Tempo 高度恢复、两侧按钮对齐及 SHIFT 切换。
- 最终串行 Release 回调测试 **3 项通过**：256-frame 双碟 p50 **0.198 ms**、p99 **0.238 ms**（预算 5.333 ms）；128-frame 抓碟 p50 **0.088 ms**、p99 **0.119 ms**（预算 2.667 ms）。两碟每回调反复 Cue：128 frames p50 **1.078 ms**、p99 **1.209 ms**，512 frames p50 **1.366 ms**、p99 **1.468 ms**（预算分别 2.667／10.667 ms）。70 项效果最慢 Spiral p99 **0.0497 ms／256 frames**。
- 测量波动：首次 Cue p99 **1.339 ms** 略超其 50% 预算门限，当时发现一个残留测试实例；关闭后单项与全套 Cue 复测通过。另一次完整运行 SpaceEcho p99 **0.1375 ms** 超过 0.12 ms 门限；待窗口与工具界面静止后，全套串行复测通过。未放宽门限；记录波动，不将一次通过作为硬实时保证。

## 本轮：按住 Play 持续减速

- 保留 400 ms 长按识别，取消 1.2 秒自动停止。速度按音频采样时钟持续下降，曲线详见 [AUDIO_DSP.md](../reference/AUDIO_DSP.md)。松手停止，失焦释放按住状态；自然 EOF 清理 Brake。降速尾部保留当前慢速并用原有 1 ms 去点击斜坡结束，下次启动恢复保存的 tempo／key。
- 修复小于一帧的播放步长在最后一个采样点被钳住、不能触发 EOF 的问题。迟到的松手不会重启曲目，也不会影响换入另一首曲目的碟机。
