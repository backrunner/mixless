# NI template-specific MIDI preset

Author: mixless contributors. Independently authored preset and fixtures are
licensed under MPL-2.0; see the repository LICENSE. NI software/templates are
not included.

Requires the unmodified Controller Editor 2.8.2 `Serato Scratch Live 2.2.nckx1` template,
Basic page and MIDI mode. The preset notes describe the independent mixless
layout and omissions. These addresses are template-specific, not factory defaults.
See [NI_COMPATIBILITY.md](../../NI_COMPATIBILITY.md) for source fingerprints.

`fixture.json` has independently authored expectations. `trace.json` pins them
to `preset.json` for offline replay. Inputs are synthetic, not device captures.
The preset is protocol implemented; hardware, firmware and OS behavior have
not been verified.
